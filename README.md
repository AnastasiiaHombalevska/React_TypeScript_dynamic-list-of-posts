#Dynamic_list of posts with React/TypeScript

This is a React + TypeScript app for viewing users, posts, and comments.

[DEMO LINK]()

#Main_functionality:
- Select a user from a dropdown and load their posts.
- View posts in a table with loading and error states.
- Open a post in a sidebar to see details and comments.
- Load comments with support for loading, empty state, and errors.
- Add new comments using a form (with validation and loading state).
- Delete comments instantly for better UX.
- Handle API interactions with proper error handling and retry support.

👉 In short: a simple CRUD app for users, posts, and comments with good UI states and API handling.
